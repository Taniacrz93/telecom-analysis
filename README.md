# ConnectaTel Analysis – Sprint 7

Este repositorio contiene el análisis realizado durante el **Sprint 7** del Bootcamp de Data Analyst de TripleTen para el caso **ConnectaTel**.

El proyecto analiza el comportamiento de los clientes de una empresa de telecomunicaciones a partir de tres datasets (`users_latam`, `usage` y `plans`). Durante el análisis se identifican problemas de calidad de datos, se realiza un análisis exploratorio, se segmentan los clientes por edad y nivel de uso y se generan recomendaciones para el negocio.

## 📂 Contenido del repositorio

- `S7_Version_Estudiante_Project_ConnectaTel.ipynb`
  → Notebook principal con limpieza de datos, análisis exploratorio (EDA), visualizaciones, segmentación de clientes e insights ejecutivos.

- `README.md`
  → Descripción del proyecto e instrucciones para reproducir el análisis.

## 📘 Cómo reproducir el análisis

1. Abre `S7_Version_Estudiante_Project_ConnectaTel.ipynb`.
2. Asegúrate de que los archivos `users_latam.csv`, `usage.csv` y `plans.csv` se encuentren disponibles en la ruta utilizada por el notebook.
3. Ejecuta todas las celdas en el orden en que aparecen.
4. El notebook realiza automáticamente la limpieza, el análisis exploratorio, la segmentación de clientes y la generación de gráficos e insights.

## 🧠 Objetivo del análisis

- Identificar problemas de calidad de los datos.
- Limpiar y preparar la información para su análisis.
- Analizar el comportamiento de los clientes mediante estadísticas descriptivas y visualizaciones.
- Segmentar a los clientes por edad y nivel de uso.
- Detectar valores atípicos y evaluar su impacto.
- Generar recomendaciones para apoyar la toma de decisiones comerciales.

Proyecto desarrollado como parte del **Sprint 7 del Bootcamp de Data Analyst de TripleTen**.
